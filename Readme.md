# AccounTalk - Fronted
Platforma web diseñada para profesionales y estudiantes que desean dominar la terminologia y practica contable en inglés 

## Tecnologias utilizadas
HTML (Estructura semantica)
CSS (Estilos y diseño responsive)
JavaScript (Interactividad y validaciones)

## Secciones principales
1. **Hero Section:** Propuesta de valor y llamado a la acción.
2. **About / Propósito:** Porque aprender contabilidad en inglés abre oportunidades laborales. 
3. **Módulos / Cursos:** Desglose de temas 
4. **Formulario de contacto:** Registro de interés para clases o asesorias.

## Instalacion y ejecución
Abrir el archivo 'index.html' en el navegador.
